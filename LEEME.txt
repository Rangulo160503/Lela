PANADERIA LELA — INSTRUCCIONES
===============================

OPCION A — ZIP / carpeta en la PC de la panaderia
-------------------------------------------------
1) Extraiga la carpeta en la COMPUTADORA PRINCIPAL
   (ej. C:\Panaderia-Lela).
2) Doble clic en:  Iniciar.bat
   - Actualiza el codigo desde GitHub (git pull; instala Git si falta).
   - NO borra datos: BD vive en %LOCALAPPDATA%\PanaderiaLela\data
     (y la carpeta data\ del programa se migra sola si tenia datos).
   - Instala Node si falta, dependencias y arma la UI.
   - Reinicia si ya estaba corriendo.
   - Abre un link publico (tunel) y deja la ventana abierta.
3) Acceso segun dispositivo:
   iPad / iOS 9 (caja):  SOLO Wi-Fi local HTTP
     Abrí http://IP-DE-LA-PC:3000/  (esta en ipad-url.txt al iniciar)
     El link trycloudflare NO abre en iPad viejo (certificado HTTPS).
   Empleados en la PC:  http://127.0.0.1:3000/
     Facturar · Saldos · Gastos · Cierre
   Celulares modernos / clientes: link del tunel + /menu
   Datos de la vitrina (nombre, horario, telefono…):
     Config → Menú público (admin).
4) Para apagar:  Detener.bat

Solo hay DOS botones:
  Iniciar.bat  = actualizar (git) / encender / reiniciar / tunel
  Detener.bat  = apagar todo

OPCION B — Descargar desde GitHub
---------------------------------
1) En https://github.com/Rangulo160503/Lela
   Code → Download ZIP → extraer.
2) Ejecutar Iniciar.bat (igual que arriba).
   La primera vez necesita Internet (Git/Node + npm + tunel).
   No hace falta Python ni Visual Studio: usa binarios precompilados.

Si Iniciar fallo a medias (npm / Python / remote origin):
  - Borrar la carpeta node_modules
  - Volver a ejecutar Iniciar.bat (se limpia solo y reintenta)
  - O descargar de nuevo el ZIP; los datos ya no dependen de la carpeta del ZIP
    (estan en %LOCALAPPDATA%\PanaderiaLela\data)

NOTAS
-----

- Dominio fijo (ej. menu.tudominio.com) se configura despues; por ahora use /menu.
