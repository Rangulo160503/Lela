Base de datos empaquetada de Panaderia Lela
==========================================

Este archivo panaderia-lela.sqlite viaja en git para que, al ejecutar
Iniciar.bat en otra PC, si la base local esta vacia o incompleta,
scripts/ensure-bundled-data.mjs la restaure automaticamente.

No editar a mano. Se actualiza desde la PC que tiene el catalogo bueno.
